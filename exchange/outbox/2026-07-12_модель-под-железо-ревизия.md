## 🎯 Рекомендованный стек проекта

### Этап 1 R2 (Стабильный сигнал) — основное железо

```
qwen2.5:7b-instruct-q4_K_M    # 5.2 GB VRAM, основная модель
```
- Влезает полностью в 8 GB VRAM
- Quality достаточно для JSON-сигналов с reasoning
- Метрика «<10 сек» — достижима при полной загрузке в VRAM

**Почему не Qwen2.5-VL 7B (текущая)?**
- VL = vision-language, тяжелее text-only на ~1 GB
- Vision **не нужен** для трейдинга (биржа отдаёт OHLCV как JSON/числа)
- Текущая конфигурация частично оффлодится в RAM → медленно
- **Замена на text-only 7B снимет оффлоад и ускорит ответ**

### Этап 2 R2 (Консенсус + Память) — основное железо

```
# Model Router (переключает, не грузит всё сразу):
qwen2.5:3b-instruct-q4_K_M    # fast mode, 2.2 GB
qwen2.5:7b-instruct-q4_K_M   # standard mode, 5.2 GB
deepseek-r1:1.5b              # reasoning validation, 1.5 GB

# Консенсус (две модели одновременно):
qwen2.5:7b + deepseek-r1:1.5b  # 5.2 + 1.5 = 6.7 GB ✅
```

**Что изменить в плане R2:**
1. ~~«3 модели одновременно»~~ → **2 модели одновременно** (7B + 1.5B reasoning)
2. ~~«GLM-4 9B expert mode»~~ → **deepseek-r1:7b-distill** (4.4 GB, влезает поодиночке)
3. Model Router управляет **загрузкой/выгрузкой**, не держит 3 модели в VRAM

### Этап 3 R2 (Бэктест + Реплей)
Не зависит от VRAM — бэктест на CPU/исторических данных. ✅

## 🛠 Практические шаги (на основном железе)

1. **Установить Ollama** (если не установлена):
   ```bash
   # Windows: скачать с ollama.com, установка автоматически настроит GPU
   ollama --version
   ```

2. **Скачать рекомендованные модели:**
   ```bash
   # Основная (Этап 1)
   ollama pull qwen2.5:7b-instruct-q4_K_M

   # Для Этапа 2 (когда дойдём)
   ollama pull qwen2.5:3b-instruct-q4_K_M
   ollama pull deepseek-r1:1.5b
   ```

3. **Обновить конфиг v2.1 backend** (`backend/app/core/config.py`):
   ```python
   # Было:
   OLLAMA_DEFAULT_MODEL = "qwen2.5-vl-7b-instruct"
   
   # Стать:
   OLLAMA_DEFAULT_MODEL = "qwen2.5:7b-instruct-q4_K_M"
   ```

4. **Проверить скорость на основном железе:**
   ```bash
   curl -X POST http://localhost:11434/api/generate -d '{
     "model": "qwen2.5:7b-instruct-q4_K_M",
     "prompt": "Analyze BTC/USDT 1h. JSON: signal, confidence, reasons",
     "stream": false
   }'
   ```
   Цель: <10 сек (метрика Этапа 1).

5. **VRAM-чек после загрузки:**
   ```bash
   nvidia-smi --query-gpu=memory.used,memory.free --format=csv
   ```
   Должно показать ~5.2 GB used, ~3 GB free.

## 🔄 Fallback на тестовую машину (4 GB)

Если основное железо недоступно, переключить `OLLAMA_DEFAULT_MODEL` на:
```python
OLLAMA_DEFAULT_MODEL = "qwen2.5:3b-instruct-q4_K_M"  # 2.2 GB VRAM
```

Тестовая машина тянет только 3B. Expert mode и консенсус недоступны. Но pipeline сигналов работает (медленнее, без reasoning-валидации).

**Предполагаю:** основное железо — другая машина, не эта (где я работаю). Команды выше нужно выполнять на основном железе. Если нужно переключиться на основное железо через Hermes — дай IP/доступ.
